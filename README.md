# Sync Study – Smart Campus Study Partner Finder

## Project Overview

**Sync Study** is a web-based platform designed to help students find compatible study partners in real-time within their college campus. By combining location-based discovery with smart matching and communication tools, Sync Study improves productivity and collaboration among students.

Students can create verified profiles using their college email and registration number. Once logged in, they can start a study session by specifying the **subject**, **faculty**, **time slot**, and **current location**.  

A live campus map shows active users as colored markers (red for self, blue for others), making it easy to locate peers nearby. Users can send study requests, chat in-app, and form study groups with offline or online modes.

---

## Features

- ✅ Verified student signup (college email + registration number)  
- ✅ Live campus map with active user markers  
- ✅ Study session creation (subject, faculty, time, location)  
- ✅ Study request system (send, accept, reject)  
- ✅ Real-time in-app chat with file sharing  
- ✅ Group study creation (offline & online)  
- ✅ Privacy-focused location sharing and status toggle

## Demo

1. Signup with your **college email** and **registration number**  
2. Start a study session by entering subject, faculty, time, and location  
3. View the live campus map to find other active students  
4. Click a user marker to **send a study request**  
5. Accept requests to open in-app **chat** and coordinate  
6. Create group study sessions for collaborative learning

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Maps:** Leaflet.js for interactive campus mapping  
- **Storage:** LocalStorage for session and chat data
